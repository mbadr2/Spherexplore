# Spherexplore

NASA Space Apps Challenge 2026 · Planet X and SPHEREx

Spherexplore compares SPHEREx visits of the same sky patch at the same infrared colour, so real motion and brightness changes stand out. Pick one of the five official targets on a real sky map, blink between visits, view the difference image and the spectrum, and read a plain-language result.

- `index.html`: the web page (single file, works on phones; the sky map needs an internet connection)
- `SPHEREXPLORE-PROJECT.pdf`: project description, results on the five targets, and how it meets the challenge

Data: NASA/IPAC IRSA, SPHEREx Data Release 1 and Quick Release 3.
